# GOTHAM — a W Chats console meshed from all ten codex systems

> Nothing reaches a customer until it is verified: grounded, scored, red teamed.
> W Chats verifies every agent before it ever meets a customer.

This is not a copy of one design system from `mzansi-agentive/design`. It takes
**one specific, named mechanism from each of the ten** and rebuilds it in W Chats'
own material, so the console reads as its own product.

## The palette — "Brass on Petrol"

New to W Chats: not the retired dusk indigo, not the amber terminal.
A workshop instrument at night: petrol-black ground, porcelain lettering,
**brass** fittings, and one **oxblood seal** that only ever means "the gate is shut."

| role | value | law |
|---|---|---|
| ground | `#0A1416` petrol black | the bench |
| porcelain | `#E9E7DF` | every word |
| **brass** `#C79A3C` | the single accent | live, active, focus, the CTA. Never decoration. |
| **oxblood** `#A8382A` | the seal | a blocked gate, a critical finding. Rare and earned. |
| jade `#4FA88A` | pass | a verdict, never a mood |

Four eval metrics, four colours, **one colour per channel** (from VITALS): a channel's
hue appears on its trace, its numeral and its chip, and nowhere else.

## The ten borrowings

| From | Mechanism taken | What it became in W Chats |
|---|---|---|
| **WARDEN** | one attribute repaints the entire room, WebGL included | `data-gate="blocked"` — an open critical finding turns the whole console oxblood. The gate is not a badge, it is the room. |
| **CHORUS** | machine reasoning is *typeset*, word by word, with a compositor's caret | the eval judge's verdict sets itself in italic serif on the eval page |
| **VESSEL** | config values are shader uniforms on one object | the soul editor's sliders morph the agent's form in real time. The object *is* the settings' output. |
| **HIVE** | dispatch births a centroid; a capped-speed swarm streams to it | ingesting a document streams its chunks into a cluster you can watch form |
| **MERIDIAN** | the command surface is permanent, never a modal; running replaces it in place | the console's command strip, and the run that takes its place |
| **ORRERY** | engraved plate furniture: brass hairlines, double rules, registration crosshairs | the bench's fittings. No shadows anywhere; hierarchy is engraved. |
| **DARKROOM** | an environmental light change is a real product state, and it eases | the gate flip runs on a 600ms tint transition. The room changes temperature. |
| **TERRARIUM** | letting go is a ritual that enriches the substrate | a failing scenario is not deleted; it is **filed into the suite** and becomes a permanent regression test |
| **VITALS** | one colour per channel; readouts pinned to their own trace | the four ragas metrics as four channels, each numeral pinned to its own line |
| **AERIAL** | the scene escapes its window; the page *is* the instrument face | the console is one brass graticule. No cards floating on it, only whisper-zones. |

## What is new here

- **The gate is the hero.** Every other W Chats layout put the agent first. This one
  puts the thing standing between the agent and your customers first.
- **The check**: a luminous agent core held inside a brass armature. Each scenario is
  a point of light riding the cage. Failures burn oxblood. Block the gate and the
  cage goes with it.

## Laws

1. Brass is the only accent and it means live. Oxblood is the only alarm and it means shut.
2. Hairlines and spacing, never boxes-in-boxes and never a drop shadow.
3. Every number is mono and tabular. Data never sits in the display face.
4. Sentence case. Uppercase only for tracked mono micro-labels of four words or fewer.
5. No emoji in the console. The customer widget may smile; the operator may not.
6. No exclamation marks. No em dashes.
