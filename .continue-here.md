### Key design rules to carry into planning
- `skyline-w-chats.png` = whole-app body background. All layout wrappers `background:transparent`.
- Glass only on: nav, stat tiles, WorkflowCard, eyebrow pills. NEVER on cards/tables.
- Coral primary (`--accent #F4748C`). Cyan rare (max 2/screen).
- Shadows always `rgba(11,7,23,...)` violet-tinted.
- Sentence case buttons. UPPERCASE TRACKED (11px, 0.12em, 600) for micro-labels.
- `--green: #34D399` (corrected in mockups this session — use this in implementation).
- No `window.event` implicit global — pass `event` explicitly.
- `prefers-reduced-motion` guard required on all animations.
- `focus-visible` outline required on all interactive elements.
