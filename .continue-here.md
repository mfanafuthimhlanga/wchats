# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure during mockup work.

- [ ] CONSTRAINT: nested-anchor-in-card — Never put `<a>` tags inside `<a class="agent-card">` wrappers. The browser ejects the inner anchor outside the parent, causing card footer content to visually escape the card. Use `<span class="card-action">` instead. Discovered during agents-home review: footer items (id + action link) appeared floating between cards in the viewport.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| nested `<a>` in card | `<a class="card-action">` inside `<a class="agent-card">` causes browser to eject inner anchor outside card | blocking | Always use `<span class="card-action">` for action text inside card anchor wrappers |
| asymmetric stat alignment | Stats grid with first=left / middle=center / last=right creates visual chaos | advisory | Use flex with consistent gap; all stats same alignment |
| filled pill for secondary action | `.card-action` as background-filled pill overwhelms card visual hierarchy | advisory | Footer action links = plain text + accent color only |
