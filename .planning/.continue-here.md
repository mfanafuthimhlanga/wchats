# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.

- [ ] CONSTRAINT: Stale process — A PowerShell window from `start_native.ps1` held port 8000 throughout the entire debugging session. Every demo run hit the OLD API. Always verify which PID owns port 8000 with `netstat -ano | grep ":8000.*LISTEN"` before running any demo.
- [ ] CONSTRAINT: .env sourcing — Never use `source .env` or `set -a; source .env` in bash. Special chars in URLs break it silently. pydantic loads .env itself via `_find_env_file()`. Just set PYTHONPATH and run.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Stale port holder | start_native.ps1 PowerShell windows persist after bash pkill — they hold port 8000 silently | blocking | Always run `netstat -ano \| grep ":8000.*LISTEN"` first; use `Stop-Process -Id <PID> -Force` via PowerShell |
| .env bash sourcing | `source .env` or `set -a; source .env` stops on special URL chars — later vars never loaded | blocking | Never source .env in bash; pydantic _find_env_file() handles it automatically |
| Docker port conflict | Docker containers held all ports; native services couldn't bind | advisory | `docker ps` before starting native stack; `docker compose down` if containers running |
