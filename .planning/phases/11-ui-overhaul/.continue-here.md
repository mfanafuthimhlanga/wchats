## Playwright Visual QA — Exact Approach

```python
from playwright.sync_api import sync_playwright

CHROMIUM = r'C:\Users\Bantu\AppData\Local\ms-playwright\chromium-1200\chrome-win64\chrome.exe'

screens = [
    ("landing",    "http://localhost:3000"),
    ("agents",     "http://localhost:3000/agents"),
    ("sign-in",    "http://localhost:3000/sign-in"),
]

with sync_playwright() as p:
    browser = p.chromium.launch(executable_path=CHROMIUM, headless=True)
    page = browser.new_page(viewport={"width": 1440, "height": 900})
    for name, url in screens:
        page.goto(url, wait_until="networkidle")
        page.screenshot(path=f"tmp_qa_{name}.png", full_page=False)
    browser.close()
```
