Create the `synthesize_retrieval_strategy` Celery pipeline task and wire it as the 5th link in the `documents.py` ingestion chain. Body:
1. Extract tenant_id, agent_id, job_id, document_ids = result.get(...). If agent_id is missing, log.error("synthesize_retrieval_strategy.invalid_result_dict", keys=list(result.keys())) and return result unchanged.

2. Idempotency + conn_str fetch in one get_sync_db() block: agent = db.get(Agent, agent_id); if agent is None: return result; if agent.retrieval_strategy and agent.retrieval_strategy != {} and not agent.strategy_resynthesis_flagged: log.info("synthesize_retrieval_strategy.idempotent_skip", agent_id=agent_id); return result. Otherwise if not agent.neon_connection_string: log.error and return result; else conn_str = fernet_decrypt(agent.neon_connection_string). NEVER log conn_str.

3. signals = _fetch_corpus_signals_sync(agent_id, conn_str); signals_json = json.dumps(signals).

4. result_container: dict = {}; wrap in try/except: asyncio.run(asyncio.wait_for(_run_strategist_loop(signals_json, result_container), timeout=60.0)) (Pitfall 2 — asyncio.run OUTSIDE, wait_for INSIDE; call _run_strategist_loop directly, no shim per PATTERNS NOTE). On Exception: log.error("synthesize_retrieval_strategy.strategist_failed", agent_id=agent_id, error=str(exc)) — then fall through to validation with empty result_container.

5. raw = result_container.get("strategy", {}); try: strategy = RetrievalStrategy.model_validate(raw) except Exception as val_exc: log.warning("synthesize_retrieval_strategy.validation_failed", error=str(val_exc)); strategy = RetrievalStrategy() (Pitfall 4 fallback to defaults).

6. Write in a NEW get_sync_db() block (do not reuse the idempotency session): agent = db.get(Agent, agent_id); if agent is not None: agent.retrieval_strategy = strategy.model_dump(); agent.strategy_resynthesis_flagged = False; db.commit().

7. After the write, emit the SSE event: open a get_sync_db() block (or reuse the write block before close) and call emit(job_id, "strategy.synthesized", {"agent_id": agent_id}, db, _redis). Guard with if job_id (skip emit if job_id missing).

8. log.info("synthesize_retrieval_strategy.complete", agent_id=agent_id); return result (chain pass-through per embed.py convention — return the same dict shape: {"tenant_id", "agent_id", "job_id", "document_ids"}).

For retry behavior on transient DB/connection errors, follow embed.py lines 380-393: if self.request.retries >= self.max_retries raise, else raise self.retry(exc=exc, countdown=2**self.request.retries). Apply only to the corpus-fetch/DB-write operations, NOT to strategist failures (those fall back to defaults rather than retry).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| chain result dict → task | agent_id arrives via positional result dict from the prior task |
| control DB → tenant DB | conn_str decrypted at runtime, never serialized into chain args |
| LLM tool output → DB write | generate_strategy output validated before persistence |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-02-01 | Information Disclosure | conn_str in chain args | mitigate | Task receives result dict with agent_id only; conn_str fetched via fernet_decrypt at runtime (CTL-08); never logged, never in args |
| T-09-02-02 | Tampering | LLM strategy output written to DB | mitigate | RetrievalStrategy.model_validate(raw) with extra="ignore"; ValidationError falls back to RetrievalStrategy() defaults — invalid output never persisted |
| T-09-02-03 | Elevation of Privilege | cross-tenant strategy write | mitigate | db.get(Agent, agent_id) scopes the write to the exact agent from the chain; no tenant iteration |
| T-09-02-04 | Denial of Service | strategist hang | mitigate | asyncio.wait_for(timeout=60.0) bounds the SDK call; failure falls back to defaults rather than blocking the chain |
</threat_model>
