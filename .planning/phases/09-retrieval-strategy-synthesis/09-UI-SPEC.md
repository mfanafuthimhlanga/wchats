## Pipeline Label Sequence

This is the complete ordered sequence of SSE event labels displayed in the amber progress badge. Phase 9 inserts one new entry between `embedding.complete` and `ingestion.complete`.

| Order | SSE Event | Display Label | Phase |
|-------|-----------|---------------|-------|
| 1 | `ingestion.started` | Starting ingestion... | M2 |
| 2 | `parsing.started` | Parsing document... | M2 |
| 3 | `parsing.complete` | Document parsed | M2 |
| 4 | `chunking.started` | Splitting into chunks... | M2 |
| 5 | `chunking.complete` | Chunks ready | M2 |
| 6 | `metadata.started` | Extracting metadata & entities... | M2 |
| 7 | `metadata.progress` | Extracting metadata & entities... | M2 |
| 8 | `metadata.complete` | Metadata extracted | M2 |
| 9 | `embedding.started` | Generating embeddings... | M2 |
| 10 | `embedding.complete` | Embeddings done | M2 |
| **11** | **`strategy.synthesized`** | **Optimising retrieval strategy...** | **M9 NEW** |
| 12 | `ingestion.complete` | Processing complete | M2 |
| 13 | `job.complete` | Done! | M2 |
| 14 | `job.failed` | Failed | M2 |

**Label copy rationale:** "Optimising retrieval strategy..." uses the same pattern as existing labels — present-participle verb phrase, lowercase, trailing ellipsis. "Optimising" (British English) is intentional — matches the project's South African English context (South Africa uses British spelling conventions). Executor may use "Optimizing" (American) if codebase style mandates it; either is acceptable.

## Interaction Contract

No new interactions are introduced. The `strategy.synthesized` label is displayed passively in the amber progress badge — the same way all other pipeline stage labels are shown. The user takes no action; the badge updates automatically as SSE events arrive.

The elapsed-time counter (`· 2m 14s`) continues ticking while `strategy.synthesized` is the active label, exactly as it does for all other stages. The synthesis Celery task typically completes in under 60 seconds; the user will see this label briefly before "Processing complete" replaces it.
