Tool-use call shape (PATTERNS.md lines 60-89, RESEARCH Pattern 3):
  ANTHROPIC_CLIENT.messages.create(
      model=HAIKU_MODEL, max_tokens=512,
      system=<judge instruction: "Call submit_verdict with your evaluation.">,
      messages=[{"role":"user","content":<delimited prompt>}],
      tools=[{"name":"submit_verdict","description":...,"input_schema":{...enum + required...}}],
      tool_choice={"type":"tool","name":"submit_verdict"},
  )
  → iterate response.content; for block.type=="tool_use" and block.name=="submit_verdict": return Model.model_validate(block.input)
  → else raise ValueError("No tool_use block returned by judge")

  _langfuse.flush()

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User message/response → judge prompt | Untrusted text crosses into the validator prompt; could attempt judge prompt injection |
| Haiku tool output → Pydantic model | Model output is untrusted until model_validate succeeds |
| Worker process → Langfuse cloud | Verdict payloads leave the process to Langfuse |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02-01 | Tampering | Judge prompt injection via user message / response_text embedded in validator prompt | mitigate | question/response/retrieved_context placed in labeled delimited sections; system prompt instructs judge to treat them as data; inputs already sanitized upstream by M4.1 soul/chunk sanitisers |
| T-05-02-02 | Tampering | Malformed Haiku output written downstream | mitigate | model_validate() before any return; ValueError raised if no submit_verdict block; verdict field_validator normalizes case (Pitfall 6) |
| T-05-02-03 | Information Disclosure | Langfuse credentials in code | mitigate | Langfuse() reads keys from env only; never passed as args; lazy-guarded init |
| T-05-02-04 | Information Disclosure | Full response_text logged to Langfuse input | accept | input payload uses response length / truncated text where practical; verdict content is operational telemetry by design (VAL-05); low PII risk for judge metadata |
</threat_model>
