<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Celery task args (Redis) → task body | agent_id/job_id/text/retrieved_context arrive via Redis broker; conn_str must NEVER be among them |
| Task → tenant DB (Auditor) | verified_qa_candidates insert crosses into per-tenant Neon project |
| Task → control DB (Auditor) | strategy_resynthesis_flagged update crosses into control DB agents table |
| Haiku verdict → DB write | unvalidated judge output must be Pydantic-validated before any insert/update |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03-01 | Information Disclosure | conn_str leaked via task args/logs | mitigate | Auditor receives agent_id only; fernet_decrypt at runtime; conn_str never logged (CTL-08); log lines reference IDs/counts only |
| T-05-03-02 | Tampering | Unvalidated Haiku output written to verified_qa_candidates / flag | mitigate | call_* return Pydantic-validated models; insert/update read typed fields only; malformed output raises in validation_service and the task's try/except logs + returns {} without writing |
| T-05-03-03 | Tampering | SQL injection via citations / question / answer into tenant insert | mitigate | All values bound as psycopg2 %s parameters; citations json.dumps then ::jsonb cast; no f-string SQL assembly |
| T-05-03-04 | Information Disclosure | False-positive verified_qa_candidate at low confidence | mitigate | Insert gated on verdict=='grounded' AND confidence >= 0.90 default threshold (D-19); auditor_confidence stored on the row for audit |
| T-05-03-05 | Denial of Service | Large retrieved_context inflating Redis task-arg size | mitigate | Plan 04 truncates retrieved_context to top-3 chunks (≤600 chars each) before dispatch; auditor only json.loads what it receives |
| T-05-03-06 | Tampering | Resynthesis flag toggled by spoofed agent_id in job_events payload | accept | job_events are written only by trusted worker tasks; payload agent_id originates from the same task chain; no external write path |
</threat_model>
