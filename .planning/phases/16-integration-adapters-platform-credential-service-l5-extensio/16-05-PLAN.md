## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-01 | Information Disclosure | consumer_secret / PAT in logs | mitigate | secrets read only via handle.use() inside the call; structlog logs only skill/status/ids |
| T-16-02 | Tampering | SSRF via site_url/URL from args | mitigate | site_url is a constructor param from config_data; Calendly base URL is a fixed module constant; no URL field in typed schemas (acceptance criterion) |
| T-16-woo-http | Tampering | WooCommerce over HTTP (auth downgrade) | mitigate | __init__ raises ValueError unless site_url is https:// (Pitfall 5, test_http_url_rejected) |
| T-16-04 | Elevation of Privilege | confused-deputy provider call | mitigate | capability envelope + Actor gate run before the adapter (dispatcher); adapter is last gate |
| T-16-cal-paid | Denial of Service | Calendly paid-plan 403 | accept | adapter surfaces 403 as an audited error; the deploy-time runbook (16-07) documents the paid-plan requirement + scheduling_url fallback |
</threat_model>
