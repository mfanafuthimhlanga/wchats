<objective>
Build the credential substrate every Phase 16 adapter rides on: the `integration_credentials` tenant-DB table (INT-01), the `PLATFORM_CREDENTIAL_KEY` setting, the per-tenant HKDF→Fernet derivation, the `CredentialHandle` in-memory secret wrapper, the `_fetch_credential_config` reader, and the `_tenant_id_var` ContextVar that supplies the HKDF salt (resolves RESEARCH Open Question 1).

Purpose: Establish per-tenant credential encryption + an agent-invisible resolution path BEFORE any adapter exists, so the raw provider credential can never reach agent code, logs, or task args (INT-02 security invariant).
Output: migration 0007, config field, credential_service.py, empty adapters package, ContextVar wiring, and the Wave-0 credential test scaffold.
</objective>

|----------|-------------|
| env → process | PLATFORM_CREDENTIAL_KEY master key enters only via env var (never DB, never logs) |

| credential service → logger/serializer | CredentialHandle is the only object that crosses; its repr is redacted |
