## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| owner's browser → capability PATCH | The screen is a convenience; the comparator on the server is the control. A staged confirmation is UX, never enforcement. |
| queue response → rendered verdict | A colour on this bench is a claim about whether an agent can be trusted with a customer. Rendering one the data does not support is a false assertion to the person deciding whether money moves. |
| row arguments → rendered text | A row's arguments carry customer email, shipping address and amounts, displayed on an operator's screen. |
