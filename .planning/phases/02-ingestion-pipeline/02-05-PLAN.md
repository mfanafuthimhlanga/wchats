<objective>
Wave 5 closes the M2 ingestion chain with `embed_and_migrate` — the fourth and last pipeline task. It generates Voyage embeddings for every chunk that does not already have one, upserts them into the tenant `embeddings` table, runs `REINDEX CONCURRENTLY` on the HNSW index, marks the job complete, and emits the terminal SSE events.

Three core responsibilities:
1. `embedding_service.embed_chunks(texts) -> list[list[float]]` — pure function that batches at 128 items per Voyage request (the API hard limit), pins `voyage-3` as the model, wraps in tenacity retry for transient errors.
2. `embed_and_migrate` Celery task — selects chunks for the document, applies Layer 4 idempotency at the SQL layer (ON CONFLICT (chunk_id) DO UPDATE), runs REINDEX, deletes the local temp file, emits `embedding.started`, `embedding.complete`, `ingestion.complete`, `job.complete`, and writes `job.status='complete'`.
3. Unit tests proving batch splitting, model pinning, ON CONFLICT call shape, REINDEX call, and terminal event order.

Purpose: This task closes the loop — after it succeeds, the chain is done and the agent's tenant DB is ready for M3 retrieval queries.
Output: `embeddings` table has one row per chunk with a 1024-dim vector and model='voyage-3'; HNSW index is fresh; job status reads 'complete'.
</objective>

    Public function:

    def embed_chunks(texts: list[str]) -> list[list[float]]:
        """Embed a list of texts in 128-item batches.

        Args:
            texts: List of pre-sanitized chunk text strings.

        Returns:
            List of 1024-dimensional float vectors, same order as input texts.
            len(return_value) == len(texts) always.
        """
        if not texts:
            return []
        all_embeddings: list[list[float]] = []
        for i in range(0, len(texts), BATCH_SIZE):
            batch = texts[i : i + BATCH_SIZE]
            log.debug("embedding_service.batch", batch_start=i, batch_size=len(batch))
            all_embeddings.extend(_embed_batch(batch))
        if len(all_embeddings) != len(texts):
            raise RuntimeError(
                f"embedding count mismatch: got {len(all_embeddings)}, expected {len(texts)}"
            )
        return all_embeddings

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-05-04 | Repudiation | task retry | mitigate | Layer 4 idempotency at SQL level: ON CONFLICT (chunk_id) DO UPDATE. Pre-fetch only fetches chunks where embedding row is missing (LEFT JOIN ... WHERE e.chunk_id IS NULL) — re-runs do near-zero work |
