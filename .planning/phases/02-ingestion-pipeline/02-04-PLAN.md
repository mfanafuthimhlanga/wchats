<objective>
Wave 4 builds the third pipeline task: `generate_metadata`. It enriches each chunk with a summary, keywords, hypothetical questions, AND entities — all in a single Claude Haiku structured-output call (per CONTEXT.md decision: entity extraction is NOT deferred; it runs in the same call as metadata).

Three core responsibilities:
1. `metadata_service.enrich_chunk(text)` — Pydantic-validated structured output via `client.messages.parse()` returning a `ChunkMetadataAndEntities` object with four fields: summary, keywords, questions, entities. Wrapped in tenacity retry against transient Anthropic errors only.
2. `generate_metadata` Celery task — iterates chunks per document, applies Layer 3 idempotency (skip chunks already in chunk_metadata), calls Haiku, UPSERTs chunk_metadata, UPSERTs entities by (normalized, type), and links chunk_entities.
3. Unit tests proving the single-call entity contract, Layer 3 skip, and ON CONFLICT shape for entity dedup.

Purpose: Entities populated here are the substrate M3 will use for metadata-filtered retrieval, and M10 will use for the Conversation-Insights Engine. Doing them in the same Haiku call costs nothing extra.
Output: For each chunk, exactly one row in `chunk_metadata` and N rows in `chunk_entities` (entities deduplicated across the corpus).
</objective>

    def enrich_chunk(text: str) -> ChunkMetadataAndEntities:
        """Single Haiku call returning summary + keywords + questions + entities.

        Tenacity retries ONLY on rate-limit/timeout. Authentication errors,
        validation errors, and content-policy errors are fatal — do not retry
        (we'd just burn budget hitting the same wall).
        """
        result = _anthropic.messages.parse(
            model=HAIKU_MODEL,
            system=METADATA_SYSTEM_PROMPT,
            messages=[{"role": "user", "content": text}],
            max_tokens=1024,  # 512 for summary/keywords/questions + room for entities
            output_format=ChunkMetadataAndEntities,
        )
        return result.parsed_output

    def generate_metadata(self, result: dict) -> dict:

    Body:
    1. Extract tenant_id, agent_id, job_id, document_ids from result.
    2. with get_sync_db() as db: fetch agent; decrypt pooled conn_str.
    3. tenant_conn = psycopg2.connect(conn_str); try/finally close.

    4. For each doc_id:
       a. Fetch all chunks for this doc: `SELECT id, content FROM chunks WHERE document_id = %s ORDER BY ordinal`.
       b. emit(job_id, "metadata.started", {"document_id": doc_id, "chunk_count": <count>}, db, _redis).
       c. For each (chunk_id, content) row:
          # Layer 3 idempotency: skip if metadata already exists
          cur.execute("SELECT COUNT(*) FROM chunk_metadata WHERE chunk_id = %s", (chunk_id,))
          if cur.fetchone()[0] > 0:
              log.info("generate_metadata.already_enriched", chunk_id=str(chunk_id))
              continue

          # Single Haiku call — summary + keywords + questions + entities together
          meta = enrich_chunk(content)

          # UPSERT chunk_metadata
          cur.execute(
              """
              INSERT INTO chunk_metadata (chunk_id, summary, keywords, questions)
              VALUES (%s, %s, %s, %s)
              ON CONFLICT (chunk_id) DO UPDATE
                  SET summary   = EXCLUDED.summary,
                      keywords  = EXCLUDED.keywords,
                      questions = EXCLUDED.questions
              """,
              (chunk_id, meta.summary, meta.keywords, meta.questions),
          )

          # UPSERT entities + link chunk_entities
          for entity in meta.entities:
              cur.execute(
                  """
                  INSERT INTO entities (name, type, normalized)
                  VALUES (%s, %s, %s)
                  ON CONFLICT (normalized, type) DO UPDATE
                      SET name = EXCLUDED.name
                  RETURNING id
                  """,
                  (entity.name, entity.type, entity.normalized),
              )
              entity_id = cur.fetchone()[0]
              cur.execute(
                  """
                  INSERT INTO chunk_entities (chunk_id, entity_id)
                  VALUES (%s, %s)
                  ON CONFLICT DO NOTHING
                  """,
                  (chunk_id, entity_id),
              )

          tenant_conn.commit()  # commit per chunk for Layer 3 partial-progress safety on retry

       d. emit(job_id, "metadata.complete", {"document_id": doc_id}, db, _redis)
       e. log.info("generate_metadata.complete", document_id=doc_id)

    5. On exception: tenant_conn.rollback(); log; raise self.retry(exc=exc, countdown=2**self.request.retries).

    6. Return: {"tenant_id": tenant_id, "agent_id": agent_id, "job_id": job_id, "document_ids": document_ids}.

    Module docstring: name chain position (3rd of 4), Layer 3 idempotency mechanism, entity dedup design.

    Note for executor: ON CONFLICT (normalized, type) DO UPDATE SET name = EXCLUDED.name is used so the human-readable name reflects the most recent occurrence; the canonical normalized form is the dedup key.
