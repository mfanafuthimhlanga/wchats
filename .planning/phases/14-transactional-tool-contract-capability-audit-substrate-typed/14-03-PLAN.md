<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tool handler → capability_envelopes | The access-control decision point; a fail-open bug here authorizes every mutating tool |
| Celery retry (acks_late) → idempotency table | A retry after Redis loss must NOT re-execute a mutation; the control-DB UNIQUE is the only durable guard |
| tool execution → tool_calls_audit | The forensic record; an audit gap defeats retrospective alerting and accountability |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-03-01 | Elevation of Privilege | missing/disabled envelope treated as enabled | mitigate | Fail-closed: None or enabled=false → denial + capability.denial log; no pass-through path exists |
| T-14-03-02 | Repudiation | replay double-execute under acks_late | mitigate | Idempotency stored in control-DB tool_idempotency_keys (UNIQUE) with ON CONFLICT DO NOTHING — survives Redis restart |
| T-14-03-03 | Information Disclosure | cross-tenant data in capability_snapshot | mitigate | Snapshot is the agent's own row converted to a plain dict, scoped by agent_id; no other agent's row is read |
| T-14-03-04 | Repudiation | audit gap on error path | mitigate | write_audit_row is called once per execution on BOTH success and error; error column captures failures |
| T-14-03-05 | Denial of Service | rate-limit evasion | mitigate | Redis INCR per (agent_id, skill, window); documented approximate under concurrency, exact limiting deferred to Phase 18 |
| T-14-03-SC | Tampering | dependency supply chain | accept | No new packages — redis/sqlalchemy/structlog already pinned and in use |
</threat_model>
