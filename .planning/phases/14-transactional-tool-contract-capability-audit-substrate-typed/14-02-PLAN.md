## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude tool-call arguments → Pydantic schema | The L1 contract: untrusted, possibly prompt-injected arguments are forced through typed validation before any handler logic |
| actor_seam stub → Phase 15 gate | The seam is the ONLY pre-execution hook for mutating tools; its existence and signature must be exactly what Phase 15 fills |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-02-01 | Tampering | coerced tool args via prompt injection | mitigate | L1 typed Pydantic schemas — no string-blob/SQL/URL/open-dict fields; amount fields are int with ge=0 |
| T-14-02-02 | Elevation of Privilege | runtime-inferred mutating flag | mitigate | mutating is a literal definition-time field in TOOL_REGISTRY; Phase 15 keys on it, never re-derives it |
| T-14-02-03 | Tampering | real side effects leaking in Phase 14 | mitigate | StubProviderAdapter is strictly offline ([STUB] outputs); real adapters are Phase 16 behind the same ABC |
| T-14-02-SC | Tampering | dependency supply chain | accept | No new packages — pydantic/anthropic already pinned and in use |
</threat_model>
