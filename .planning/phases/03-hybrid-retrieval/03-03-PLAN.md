      14. payload = {"query": query, "results": reranked,
                     "trace": trace, "strategy_used": strategy.model_dump()}
      15. emit(job_id, "query.complete", payload, db, _redis)
      16. job.status = "complete"; job.finished_at = datetime.now(timezone.utc); db.commit()

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Celery message → task | job_id, agent_id, query arrive from Redis; agent_id validated against control DB |
| task → control DB | Agent and Job fetched by ID; tenant ownership enforced in route (Plan 04) |
| task → tenant DB | Connection string fetched encrypted, decrypted via fernet_decrypt() at runtime |
| task → Voyage API | query text sent to Voyage embed + rerank; response shape validated |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-09 | Information Disclosure | retrieve_and_rank — log statements | mitigate | Never log full query text; log job_id, agent_id, and counts only |
| T-03-10 | Information Disclosure | retrieve_and_rank — return value | accept | Returns {} only; no connection strings, no query vectors, no API keys in return |
| T-03-11 | Tampering | idempotency guard — job_events check | accept | SELECT 1 check is read-only; only skips re-execution, never silently corrupts state |
| T-03-12 | Denial of Service | rrf_fuse — large fused candidate set | accept | final_k from RetrievalStrategy (default 5); Voyage rerank top_k bounded by final_k |
| T-03-13 | Spoofing | agent_id from task args | mitigate | db.get(Agent, agent_id) fetches from control DB — agent must exist; ownership enforced at route dispatch (Plan 04) |
</threat_model>
