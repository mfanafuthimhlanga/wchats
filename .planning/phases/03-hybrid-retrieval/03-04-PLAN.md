the Pydantic schemas, and register the router in main.py. This closes the HTTP surface

<!-- From apps/api/app/api/v1/documents.py — route pattern (agent validation + job creation + dispatch) -->
@router.post("/agents/{agent_id}/documents", status_code=202, response_model=DocumentUploadResponse)
async def upload_documents(agent_id: UUID, ..., db: AsyncSession = Depends(get_async_db),
                            tenant: Tenant = Depends(get_current_tenant)):
    result = await db.execute(
        select(Agent).where(Agent.id == agent_id, Agent.tenant_id == tenant.id, Agent.deleted_at.is_(None))
    )
    agent = result.scalar_one_or_none()
    if agent is None:
        raise HTTPException(status_code=404, detail="Agent not found")
    if agent.status != "ready":
        raise HTTPException(status_code=409, detail=f"Agent is not ready (status={agent.status})")
    job = Job(tenant_id=tenant.id, agent_id=agent.id, kind="ingest_documents", status="pending")
    db.add(job); await db.commit(); await db.refresh(job)
    chain(...).apply_async(queue="pipeline", ...)
    return DocumentUploadResponse(job_id=job.id, ..., events_url=f"/jobs/{job.id}/events")

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → POST /agents/{id}/query | Untrusted query string from caller; validated by Pydantic QueryRequest |
| Route → Celery | Only (job_id, agent_id, query) dispatched — no connection string, no API key |
| Route → control DB | Agent ownership check: Agent.tenant_id == tenant.id AND deleted_at IS NULL |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-14 | Information Disclosure | POST query — log body.query | mitigate | body.query never logged — only job_id and agent_id logged (T-03-09 from task) |
| T-03-15 | Elevation of Privilege | Cross-tenant query dispatch | mitigate | Agent.tenant_id == tenant.id filter ensures agent belongs to authenticated tenant before dispatch |
| T-03-16 | Tampering | QueryRequest.filters field | accept | filters field accepted but not applied in M3 (empty list default); applied in M4+ |
| T-03-17 | Denial of Service | GET /queries — unbounded result | mitigate | LIMIT 50 on query jobs list; no full-table scan possible |
| T-03-18 | Injection | QueryRequest.query min_length=1 | mitigate | Pydantic min_length=1 rejects empty queries before dispatch; SQL injection impossible (psycopg2 parameterized) |
</threat_model>
