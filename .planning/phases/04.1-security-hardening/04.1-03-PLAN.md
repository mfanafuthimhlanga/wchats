<objective>
Implement per-tenant daily budget ceiling (F4 — CRITICAL):

Without this fix, an attacker who creates a fresh conversation_id per request
(each capped at the $0.05 per-conversation limit) can send 60 req/min = $3/min
= $4,320/day against any agent with no tenant-level ceiling. The per-conversation
cap never fires because each conversation is a fresh slot.

Fix adds four layers:
1. Settings field TENANT_DAILY_BUDGET_USD (global default $5.00/day).
2. Alembic migration 0008 adding tenants.daily_budget_usd for future per-tenant
   overrides (admin UI wiring deferred to M5).
3. New service apps/api/app/services/budget.py with check_and_increment_budget
   that uses Redis INCRBYFLOAT to track spend per tenant per day with 24h TTL.
4. Budget guard in POST /widget/{agent_id}/chat that checks before dispatching
   the Celery task and returns 429 with Retry-After: 3600 when exhausted.

Purpose: Closes the most severe cost-attack vector on the platform before any
further public exposure. All Anthropic spend goes through the POST /chat handler.

Output: Extended config.py, new migration 0008, new budget.py service, modified
widget.py chat handler, new test_budget.py with 4 tests.
</objective>

New file apps/api/app/services/budget.py:
  import time
  from redis.asyncio import Redis

  async def check_and_increment_budget(
      tenant_id: str, cost_usd: float, redis: Redis, ceiling_usd: float
  ) -> bool:
      key = f"budget:{tenant_id}:{_today()}"
      current = float(await redis.get(key) or 0.0)
      if current >= ceiling_usd:
          return False
      await redis.incrbyfloat(key, cost_usd)
      await redis.expire(key, 86400)
      return True

  def _today() -> str:
      return time.strftime("%Y-%m-%d")

Budget guard to add to post_widget_chat (insert between step 5 and step 6):

      redis_client,
      settings.TENANT_DAILY_BUDGET_USD,
  )
  if not budget_ok:
      raise HTTPException(
          status_code=429,
          detail="Daily usage limit reached. Please try again tomorrow.",
          headers={"Retry-After": "3600"},
      )
