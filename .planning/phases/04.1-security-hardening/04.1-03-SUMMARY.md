### Task 2: Budget Service + Guard (TDD)

**apps/api/app/services/budget.py (new):**
- `check_and_increment_budget(tenant_id, cost_usd, redis, ceiling_usd) -> bool`
- Uses `redis.get` to read current spend, checks against ceiling, then `redis.incrbyfloat` + `redis.expire(86400)`
- `_today()` returns UTC date string for key partitioning

**apps/api/app/api/v1/widget.py (modified):**
- Added `from app.services.budget import check_and_increment_budget`
- Added module-level `ESTIMATED_TURN_COST_USD = 0.01`
- Inserted budget guard between step 5 (job creation) and step 6 (Celery dispatch):
  - Calls `check_and_increment_budget` with tenant_id, cost, redis, ceiling
  - Returns 429 with `Retry-After: 3600` if budget exhausted
  - Celery `apply_async` is never called when budget is exhausted
