> Each was discovered through actual failure this session. Acknowledge before proceeding.

- [ ] CONSTRAINT: **Cloudflare *quick* tunnels do NOT deliver SSE** — the widget streams answers over SSE; a `cloudflared tunnel --url` quick tunnel returns 0 bytes (events buffer, never flush). MITIGATION: use **localhost.run** (`ssh -R 80:localhost:8000 nokey@localhost.run` → random `https://*.lhr.life` URL) which DOES stream SSE (verified). Do not waste a session re-testing cloudflared quick tunnels for the live demo.
- [ ] CONSTRAINT: **Do NOT push an embed with an empty `data-api` to a live site** — it deploys a non-functional chat widget. The `data-api` MUST be set to the current live tunnel URL (a `*.lhr.life` URL, which changes each session) before committing/pushing the portfolio.

**Do not proceed until both boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Quick-tunnel SSE | cloudflared quick tunnel buffers SSE → widget hangs on "typing…" forever even though the agent answered | blocking | Use localhost.run (SSH tunnel) for the demo; it streams SSE. cloudflared quick tunnel is HTTP-only. |
| Empty data-api deploy | Pushing the embed with `data-api=""` deploys a dead widget to the public portfolio | blocking | Wire the live `*.lhr.life` URL into `data-api` BEFORE commit+push; or have the widget read the api base from an editable `wchats/config.json` fetched at runtime |
| Unit-test-only "resolved" | Empty-answer bug was wrongly declared fixed on unit tests alone (cycle 1); real cause was a 2nd cap only a live turn exposed | advisory | For agent-behavior changes, LIVE-verify a real turn (non-empty grounded answer) — instrument the SDK ResultMessage (`subtype`/`total_cost_usd`/`num_turns`), don't guess |
| Tunnel-before-warm | Starting cloudflared while uvicorn+worker were cold-importing (4GB box) timed out the tunnel's setup request | advisory | Start the tunnel only AFTER `/health` returns 200 and the worker logs `ready.` (cold import ≈108–144s) |
