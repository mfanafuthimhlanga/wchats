<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → Cloudflare edge (*.trycloudflare.com) | the only external entry point; TLS terminates here, then an outbound-only tunnel carries traffic to the PC (no inbound ports opened) |
| cloudflared → uvicorn 0.0.0.0:8000 | uvicorn binds 0.0.0.0 so cloudflared (and LAN devices) can reach it; the public path is exclusively via the Cloudflare edge |
| local .env → process environment | all secrets (Neon/Upstash/Anthropic/Voyage/JWT/Clerk) are loaded into the process env by start_demo.ps1 and inherited by child windows; never printed, never in Celery task args |
| widget JWT mint route → deployed agent | /widget/{agent_id}/config requires a valid deployed agent_id; mints a 15-min HS256 JWT |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-05-01 | Information Disclosure | someone enumerates / guesses the random *.trycloudflare.com subdomain while a demo is live | mitigate | The agent-config + JWT-mint route requires a valid deployed agent_id (404 otherwise); the minted widget JWT expires in 15 min (existing); the per-IP rate limit (10 req/min, existing in widget.py) caps abuse; the URL is ephemeral (changes every session) so it is not a durable target |
