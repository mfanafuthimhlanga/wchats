<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → VM public IP | the VM is internet-exposed; only 443 should be reachable |
| Caddy :443 → uvicorn 127.0.0.1:8000 | TLS terminates at Caddy; uvicorn never publicly bound |
| VM filesystem → secrets (.env, DUCKDNS_TOKEN) | secrets at rest on the VM must be access-restricted |
| runtime worker → Anthropic/Voyage/Neon | API keys leave the VM only as authenticated calls, never logged or in task args |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-05-01 | Information Disclosure | secrets in /opt/wchats/apps/api/.env readable by other users | mitigate | `chmod 600` + `chown wchats:wchats`; loaded only via systemd EnvironmentFile; never echoed |
| T-12-05-02 | Spoofing / DoS | VM exposed on ports beyond 443 | mitigate | OCI Security List allows only TCP 443; host iptables ACCEPT only 443 (persisted); uvicorn binds 127.0.0.1; port 80 closed (DNS-01) |
| T-12-05-03 | Information Disclosure | DUCKDNS_TOKEN co-located with app secrets | mitigate | Token isolated in Caddy's systemd drop-in (mode 600), absent from app .env (acceptance grep == 0) |
| T-12-05-04 | Repudiation / Information Disclosure | Anthropic/Voyage/Neon keys logged or passed in Celery task args | mitigate | Keys env-only; tasks receive agent_id and decrypt conn_str at runtime (CLAUDE.md invariant, unchanged); structlog does not log keys |
| T-12-05-05 | Tampering | runtime worker silently running prefork (module-globals unsafe) | mitigate | Unit pins --pool=solo --concurrency=1 (plan 04); journalctl confirms solo at runtime |
| T-12-05-06 | Elevation of Privilege | self-signed / invalid TLS accepted by clients | mitigate | Caddy obtains a real Let's Encrypt cert via DNS-01; acceptance requires `curl` to validate WITHOUT `-k` |
</threat_model>
