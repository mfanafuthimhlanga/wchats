<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| hiring-manager browser → Vercel CDN (/wchats/*) | public static delivery of loader + bundle (untrusted clients fetch these) |
| widget loader → sandboxed iframe → VM API (data-api host) | the loader hands a runtime-supplied API host to the iframe |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-02-01 | Tampering | a baked-in API host forcing a rebuild (and a stale/wrong host) on repoint | mitigate | D-07: data-api is read at runtime from the snippet attribute; no host is hard-coded in the bundle/loader, so repointing is a config change not a code change |
| T-12-02-02 | Information Disclosure | secrets accidentally shipped in the public static bundle | mitigate | Only loader + Preact bundle + css + iframe host are published; no env file, no API key, no conn string is copied into public/wchats/ — verified by acceptance grep that no hostname/secret is baked in |
| T-12-02-03 | Spoofing | a malicious page embedding the widget against the real agent | accept | The widget JWT is minted per-config-request with a 15-min expiry (existing widget.py control); CORS is wildcard by design for an embeddable widget; abuse is rate-limited by the per-agent SSE concurrency cap. Low value, public-by-design surface. |
</threat_model>
