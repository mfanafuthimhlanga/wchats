## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| systemd unit file → secrets | unit files could leak secrets if inlined; they must reference EnvironmentFile only |
| public internet → Caddy :443 → uvicorn 127.0.0.1:8000 | TLS terminates at Caddy; uvicorn is never publicly bound |
| smoke script → live API over HTTPS | the script sends a public widget question and a minted JWT; must not embed or echo secrets |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-04-01 | Information Disclosure | secrets inlined in systemd unit files | mitigate | Units use `EnvironmentFile=/opt/wchats/apps/api/.env` only; acceptance grep confirms no key/conn-string literal in deploy/ |
| T-12-04-02 | Spoofing / DoS | VM public IP exposed beyond 443 | mitigate | deploy/README.md mandates OCI Security List + host iptables allowing ONLY 443; uvicorn binds 127.0.0.1 (not 0.0.0.0); port 80 stays closed (DNS-01 ACME) |
| T-12-04-03 | Information Disclosure | DUCKDNS_TOKEN placed in app .env or unit | mitigate | Caddyfile comment + README route DUCKDNS_TOKEN to Caddy's own systemd drop-in (caddy.service.d/override.conf), isolated from app secrets |
| T-12-04-04 | Tampering | Celery worker running prefork and corrupting module-level globals | mitigate | ExecStart pins `--pool=solo --concurrency=1` explicitly so prefork can never be selected (STATE.md [04-02]) |
| T-12-04-05 | Information Disclosure | smoke script echoing the minted JWT or an API key into logs | mitigate | Script reads secrets from env, never echoes token/key; acceptance grep confirms no secret literal |
</threat_model>
