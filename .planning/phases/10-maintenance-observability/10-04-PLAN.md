## Task 1 — AlertsBanner component

<read_first>
- `apps/admin/app/agents/[id]/page.tsx` — read in full before writing; extract the auth pattern (lines 65-77: `useAuth`, `getToken`, `Authorization: Bearer ${token}`, `apiBase`), the error-alert inline style pattern (lines 333-348), and the JSX structure to understand mount location.
- `.planning/phases/10-maintenance-observability/10-UI-SPEC.md` — AUTHORITATIVE design contract. Read this before writing ANY JSX. All visual decisions (row surface colors, badge classes, spacing, typography, Langfuse link markup, triggered_at format) come from this spec.
- `.planning/phases/10-maintenance-observability/10-PATTERNS.md` — AlertsBanner pattern section (lines 26-138). Contains the exact component skeleton and critical override notes.
</read_first>

Create `apps/admin/app/agents/[id]/components/AlertsBanner.tsx` as a `"use client"` component. The component must:

- Accept a single prop: `{ agentId: string }`. No `apiKey` prop — auth is handled via Clerk (per D-auth pattern and UI-SPEC).
- Import `useAuth` from `"@clerk/nextjs"`. Call `const { getToken } = useAuth()` at component top.
- `apiBase` from `process.env.NEXT_PUBLIC_API_BASE || ''`.
- `fetchAlerts` must: call `const token = await getToken()`, guard `if (!token) return`, then `fetch(${apiBase}/api/v1/agents/${agentId}/alerts, { headers: { Authorization: \`Bearer ${token}\` } })`. Catch silently.
- Poll via `setInterval(fetchAlerts, 30_000)` inside `useEffect([agentId])`. Clear on unmount.
- Return `null` when `alerts.length === 0`. No empty state.

Alert row structure (per UI-SPEC):
- Outer div: flex, `items-start justify-between`. Inline styles for background/border (CSS vars, not Tailwind surface classes). Use `role="alert"`.
- Left side: severity `<span>` badge (Tailwind `bg-amber-100 text-amber-800` or `bg-red-100 text-red-800`, `uppercase`, `text-xs font-semibold`, `rounded`, `px-1.5 py-0.5`) followed by alert_type label (`font-medium`, 14px/600) on the same line. Message body `<p>` on the next line (14px/400, `var(--text-3)`).
- triggered_at on a third line: format as relative time using a local `timeAgo(iso: string): string` helper (< 60s → "just now"; < 3600s → "{n}m ago"; < 86400s → "{n}h ago"; else → "{n}d ago"). Style: 12px/400, `var(--text-3)`.
- Right side: Resolve button — text link style (no background, no border), 12px, `var(--text-3)` default, `var(--text-1)` hover, underline, `ml-4 shrink-0`. On click: optimistic `setAlerts(prev => prev.filter(a => a.id !== alertId))` first, then POST with Bearer token (no error handling on POST — next poll restores if it fails).

alert_type display mapping (per UI-SPEC): `eval_regression` → "Eval Regression"; `red_team_critical` → "Critical Red Team Finding"; any other value → replace underscores with spaces, title-case.

No animation on resolve. Row disappears immediately via state update.
