<objective>
Add the `require_human` branch to `_execute_transactional_tool` in `apps/api/app/services/transactional/tools.py`, alongside the existing `block` branch at step 5, and wire the tenant `conn_str` into the `call_actor_gate` call so the Actor can read conversation history. Confirm — via a structural unit test — that the Actor is the synchronous pre-mutation node while the other three validators stay async post-response (the four-node chain, ACT-05; agent.py is NOT modified).

Purpose: Turn a `require_human` Actor verdict into a real human-approval gate. The action does not execute; instead it creates a `pending_confirmations` row (the same row `confirm_action` resolves) and returns an "awaiting approval" message to the agent. This is the L3 enforcement that makes high-risk-but-plausible actions wait for a human.

</objective>
