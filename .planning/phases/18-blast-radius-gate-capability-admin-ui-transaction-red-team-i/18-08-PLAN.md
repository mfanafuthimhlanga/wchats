Add a class docstring stating explicitly that these validators check **shape only**. The tighten-only
*direction* check is deliberately **not** here, because a Pydantic validator sees the new value in
isolation and cannot see the current DB row that tightness is relative to (OD-3). Adding it here would
produce a validator that silently permits loosening whenever the current row is not in scope.

Also set `model_config` to forbid extra fields (`extra="forbid"`) so a typo'd or an unknown field is a
422 rather than a silently ignored no-op — on an authorization surface, a silently dropped field is worse
than a rejection.

`constraints`, `requires_confirmation`, `requires_identity_verification`, `actor_mode`, `updated_at`,

**`PATCH /agents/{agent_id}/capability-envelopes/{skill}`** — the write gate. Order of operations, and
the order matters:
1. `_get_owned_agent` (IDOR first, before anything else touches the skill or the body).
2. Reject an unknown `skill` with 404 `"Skill not found"` when it is absent from
   `PLATFORM_CAPABILITY_DEFAULTS` — the six mutating skills plus `confirm_action` are the closed set.
3. Load the existing row for `(agent_id, skill)`; when absent, build the **current** state for
   comparison from the platform default for that skill (so a first write is compared against the platform
   ceiling rather than against nothing, which is what "never loosen beyond platform defaults" means).
4. `proposed = body.model_dump(exclude_unset=True)`. When it is empty, return the current serialised row
   unchanged with 200 — a no-op PATCH is not an error and must not touch `updated_at`.
5. Call `validate_tighten_only(current=<current dict>, proposed=proposed, platform_defaults=PLATFORM_CAPABILITY_DEFAULTS)`.
   On a non-`None` reason, raise `HTTPException(status_code=422, detail=<a message embedding the reason>)`
   and **return before any ORM mutation** — no `db.add`, no attribute assignment, no `db.commit()`.
6. Only on `None`: apply the proposed fields to the row (creating the row with the platform default as its
   base when it did not exist), set `updated_at` to `datetime.now(timezone.utc)`, `await db.commit()`,
   `await db.refresh(row)`.
7. `log.info("patch_capability_envelope.ok", agent_id=..., tenant_id=..., skill=..., fields=sorted(proposed.keys()))`
   — log the field **names** only, never the values.
8. Return the serialised row.
