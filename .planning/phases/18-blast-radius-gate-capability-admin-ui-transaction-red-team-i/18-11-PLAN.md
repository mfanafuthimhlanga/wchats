## Why this plan is autonomous:false

Three live gates cannot be discharged by any autonomous plan in this phase, and each mirrors how Phases
13, 15, 16, 17 and 21 handled the same class of gap — run and recorded, or explicitly deferred with
operator acceptance. **A silent skip is not acceptable** (18-VALIDATION.md § Sampling Rate).

| Gate | Why it needs an operator |
|------|--------------------------|
| RTX-04 clean-tenant zero-high-severity run | Needs a real `ANTHROPIC_API_KEY` (the confused-deputy probe drives a real Sonnet victim turn and `classify_severity` is a real Haiku call), a local Postgres for the two ephemeral databases, and a local `redis-server` for the rate layer. |
| Control migration 0019 live roundtrip | No live Neon control DB holds even the v1.2 migrations (control head applied live is 0016). Applying 0019 up and down against a real control DB is an operator action. |
| Blast-radius panel + envelope acknowledgement end-to-end | Requires the full local stack running with a real agent, and the tighten-then-approve-returns-422 round trip performed by hand. Plan 18-10's checkpoint covers the visual half; this records the data half. |
