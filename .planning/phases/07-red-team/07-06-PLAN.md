## Objective

Build `scripts/demo_m7.sh` — a local-processes-only demo script that creates an intentionally weak agent, runs the red team against it, and asserts that `deployment_blocked=true` and `max_severity=critical` appear in the result. Also build a guarded integration test (`RED_TEAM_E2E_ENABLED`) that exercises the red team HTTP routes end-to-end. Both artifacts prove RED-08: a captured prompt injection trace shows the full attack sequence with severity classification.

## must_haves

### Goal
Phase 7 delivers three adversarial red team agents + severity classification + deployment gate.

### Truths
- acks_late=True AND idempotency guard on every Celery task
- conn_str never in Celery task args — fetch from control DB by agent_id at runtime
- asyncio.run() bridge in Celery tasks (never loop.run_until_complete)
- claude-agent-sdk==0.1.81 PINNED
- No Docker — all demo scripts use local processes (redis-server, uvicorn, celery worker)
- worker_pool=solo means no Celery chord — use sequential calls inside run_red_team
