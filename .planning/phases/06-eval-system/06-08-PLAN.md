1. Imports:
   - 'use client'

   - useQuery from @tanstack/react-query
   - useAuth from @clerk/nextjs
   - Link from next/link
   - ResponsiveContainer, LineChart, Line, XAxis, YAxis, CartesianGrid, Tooltip, Legend, ReferenceLine from recharts

2. Props: { params: Promise<{ id: string }> } — use use(params) to unwrap

3. State: const [activeTab, setActiveTab] = useState<'passrates' | 'scenarios'>('passrates')
          const [isRunning, setIsRunning] = useState(false)

4. Auth + data fetching (TanStack Query pattern):
   const { getToken, isLoaded, isSignedIn } = useAuth()
   const apiBase = process.env.NEXT_PUBLIC_API_BASE || ''
   
   const evalRunsQuery = useQuery({
     queryKey: ['eval-runs', id],
     queryFn: async () => { token = await getToken(); fetch(`${apiBase}/api/v1/agents/${id}/eval-runs`, {headers:{Authorization:`Bearer ${token}`}}).then(r=>r.json()) },
     enabled: isLoaded && !!isSignedIn,
     staleTime: 30_000,
   })
   
   const latestRunId = evalRunsQuery.data?.eval_runs?.[0]?.id
   const resultsQuery = useQuery({
     queryKey: ['eval-results', id, latestRunId],
     queryFn: async () => { /* same pattern for /eval-runs/{latestRunId}/results */ },
     enabled: isLoaded && !!isSignedIn && !!latestRunId,
     staleTime: 30_000,
   })

5. Chart data transform: const chartData = (evalRunsQuery.data?.eval_runs || []).map(run => ({ date: new Date(run.started_at).toLocaleDateString(), faithfulness: run.aggregate_scores.faithfulness ?? 0, answer_relevancy: run.aggregate_scores.answer_relevancy ?? 0, context_precision: run.aggregate_scores.context_precision ?? 0, context_recall: run.aggregate_scores.context_recall ?? 0 }))

6. Run Now handler: POST `${apiBase}/api/v1/agents/${id}/eval-runs/trigger` with Authorization Bearer token. On click: set isRunning=true, fire POST, on 202 response start polling evalRunsQuery every 5s (use setInterval cleared on unmount or when a new run appears in the list). On error: set isRunning=false and show toast. Button label: "▶ Run Now" idle, "Running…" while isRunning=true. Disable button while isRunning.

7. Page structure per UI-SPEC §4:
   - Back link: ← Back to Configure (Link to /agents/{id})
   - Header row: h1 "Run evaluations" + "▶ Run Eval" button (disabled when isRunning)
   - Subtitle: "Ragas-scored nightly tests for your agent's knowledge base."
   - Tab bar: "Pass Rates" | "Scenarios"
   
8. Empty state (when evalRunsQuery.data?.eval_runs?.length === 0 or !evalRunsQuery.data):
   - Dashed card per §5.5 with 📊 icon + "No eval runs yet" title + subtitle + "▶ Run First Eval" button

9. Pass Rates tab — Recharts chart per §5.3 EXACT config:
   - ResponsiveContainer width="100%" height={320}
   - LineChart data={chartData}
   - CartesianGrid strokeDasharray="3 3" stroke="var(--border)" vertical={false}
   - XAxis dataKey="date"
   - YAxis domain={[0, 1]} tickFormatter={(v) => v.toFixed(1)}
   - ReferenceLine y={0.9} stroke="var(--border-hard)" strokeDasharray="4 4"
   - Four Lines with locked colors from §3: faithfulness #B8860B, answer_relevancy #7B1C3A, context_precision #4A7C59, context_recall #4A6080
   - Run summary strip below chart: "Last run:" + date, "Scenarios:" + count, "Duration:" + duration

10. Scenarios tab — table per §5.4:

11. Loading state: skeleton rows when evalRunsQuery.isLoading

12. All colors from Design G CSS vars only (no hardcoded hex except 2 one-off metric colors: #4A7C59, #4A6080 per UI-SPEC §3)
