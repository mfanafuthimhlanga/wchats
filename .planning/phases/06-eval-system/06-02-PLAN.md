Logic:
1. For each score in scenario_scores: if faithfulness >= settings.EVAL_FAITHFULNESS_THRESHOLD AND answer_relevancy >= settings.EVAL_RELEVANCY_THRESHOLD, find the matching scenario by scenario_id.
2. Embed the scenario question: question_vector = _get_vo().embed([scenario["question"]], model="voyage-3", input_type="query").embeddings[0]
3. INSERT INTO verified_qa (id, question, question_vector, answer, citations, source, faithfulness, relevance, promoted_at, promoted_by, use_count) VALUES (%s, %s, %s::vector, %s, %s::jsonb, 'sandbox_test', %s, %s, NOW(), 'system', 0) ON CONFLICT DO NOTHING using psycopg2 try/finally.
4. Log: log.info("verified_qa.promoted", scenario_id=..., faithfulness=..., relevance=...)
5. Return count of promoted rows.

The answer field comes from scenario.get("agent_response",""). The citations field comes from scenario.get("citations", []) serialized via json.dumps.
question_vector bound as str(question_vector) cast to %s::vector (matching retrieval_service.py pattern).
