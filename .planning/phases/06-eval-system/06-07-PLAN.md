## Objective

Create apps/api/app/api/v1/evals.py with three FastAPI routes — GET /agents/{id}/eval-runs (list runs with aggregate scores), GET /agents/{id}/eval-runs/{run_id}/results (per-scenario results), and POST /agents/{id}/eval-runs/trigger (manually dispatch run_eval_suite for the "Run Now" button) — and register the router in main.py. Read routes query the tenant DB; the trigger route dispatches a Celery task and returns immediately. All routes prevent IDOR with tenant ownership checks.

Route 1: GET /agents/{agent_id}/eval-runs
  @router.get("/agents/{agent_id}/eval-runs")
  async def list_eval_runs(agent_id: UUID, db: AsyncSession = Depends(get_async_db), tenant: Tenant = Depends(get_current_tenant)) -> dict:
  
  1. Fetch agent: agent = await db.get(Agent, agent_id); if None: raise HTTPException(404)
  2. IDOR check: if agent.tenant_id != tenant.id: raise HTTPException(403)
  3. Decrypt: conn_str = fernet_decrypt(agent.neon_connection_string)
  4. SQL: SELECT er.id, er.started_at, er.finished_at, er.status, COUNT(DISTINCT res.scenario_id) as scenario_count, AVG(CASE WHEN res.metric='faithfulness' THEN res.score END) as faithfulness, AVG(CASE WHEN res.metric='answer_relevancy' THEN res.score END) as answer_relevancy, AVG(CASE WHEN res.metric='context_precision' THEN res.score END) as context_precision, AVG(CASE WHEN res.metric='context_recall' THEN res.score END) as context_recall FROM eval_runs er LEFT JOIN eval_results res ON res.eval_run_id = er.id GROUP BY er.id, er.started_at, er.finished_at, er.status ORDER BY er.started_at DESC LIMIT 50
  5. Run via asyncio.to_thread(_query_tenant_db_sync, conn_str, sql, {})
  6. Build response matching exact shape from RESEARCH.md Section 9: {"eval_runs": [{id, started_at, finished_at, status, scenario_count, aggregate_scores: {faithfulness, answer_relevancy, context_precision, context_recall}}]}
  7. Return dict

Route 2: GET /agents/{agent_id}/eval-runs/{run_id}/results
  @router.get("/agents/{agent_id}/eval-runs/{run_id}/results")
  async def get_eval_run_results(agent_id: UUID, run_id: UUID, db: AsyncSession = Depends(get_async_db), tenant: Tenant = Depends(get_current_tenant)) -> dict:
  
  1. Fetch agent + IDOR check (same as Route 1)
  2. Decrypt conn_str
  3. SQL: SELECT res.scenario_id, es.question, es.source, res.metric, res.score FROM eval_results res LEFT JOIN eval_scenarios es ON es.id::text = res.scenario_id WHERE res.eval_run_id = %(run_id)s ORDER BY res.scenario_id, res.metric
  4. Group by scenario_id to build per-scenario score dicts
  5. Build response: {"results": [{scenario_id, question, source, scores: {faithfulness, answer_relevancy, context_precision, context_recall}, passed: bool}]}
  6. passed = all four scores >= settings.EVAL_FAITHFULNESS_THRESHOLD (both thresholds are 0.90 — use single threshold for simplicity)
  7. Return dict
</action>

Route 3: POST /agents/{agent_id}/eval-runs/trigger
  @router.post("/agents/{agent_id}/eval-runs/trigger", status_code=202)
  async def trigger_eval_run(agent_id: UUID, db: AsyncSession = Depends(get_async_db), tenant: Tenant = Depends(get_current_tenant)) -> dict:

  1. Fetch agent: agent = await db.get(Agent, agent_id); if None: raise HTTPException(404)
  2. IDOR check: if agent.tenant_id != tenant.id: raise HTTPException(403)
  3. Guard: if agent.status != "ready": raise HTTPException(400, detail="Agent must be in ready state to run evals")
  4. Dispatch: task = run_eval_suite.apply_async(kwargs={"agent_id": str(agent_id)}, queue="runtime")
  5. Log: log.info("eval_trigger.dispatched", agent_id=str(agent_id), task_id=task.id, tenant_id=str(tenant.id))
  6. Return 202: {"status": "queued", "task_id": task.id, "agent_id": str(agent_id)}

Returns 202 Accepted immediately — the eval runs asynchronously. Frontend polls GET /eval-runs to detect completion.
</action>

## must_haves

- All three routes require authentication via get_current_tenant (no anonymous access)
- Agent ownership check (agent.tenant_id == tenant.id) on every route — prevents IDOR cross-tenant access
- Tenant DB queries use asyncio.to_thread to avoid blocking FastAPI event loop
- eval_runs and eval_results queried from tenant DB — fernet_decrypt on agent.neon_connection_string required
- list_eval_runs returns aggregate_scores dict with all four metric keys (NULL → 0.0 fallback)
- get_eval_run_results returns passed: bool computed as all four scores >= threshold
- trigger route dispatches run_eval_suite.apply_async with agent_id only — no conn_str in task args (CTL-08)
- trigger route returns HTTP 202 immediately — eval is async; frontend polls GET /eval-runs for completion
- trigger route guards on agent.status == "ready" (400 if not ready)
