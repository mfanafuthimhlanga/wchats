R-02 RESOLUTION (RESEARCH.md):
  On FIRST turn (conversation_id is None):
    1. Create row in tenant conversations: (id=uuid4(), agent_id=agent_id, created_at=now(), metadata={})
    2. local_conversation_id = that uuid4
    3. Pass resume=None to SDK
    4. After SDK returns, extract ResultMessage.session_id → call it sdk_session_id
    5. UPDATE conversations SET metadata = jsonb_set(metadata, '{sdk_session_id}', to_jsonb($sdk_session_id)) WHERE id = $local_conversation_id
    6. Return local_conversation_id to the widget in agent.response payload
  On SUBSEQUENT turn (conversation_id provided):
    1. SELECT id, agent_id, metadata FROM conversations WHERE id = $conversation_id AND agent_id = $agent_id
    2. If no row → emit agent.error + return (ownership guard)
    3. sdk_session_id = metadata.get("sdk_session_id")
    4. Pass resume=sdk_session_id to SDK
