<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent → tool args | Untrusted LLM-generated tool arguments cross into our process; treated as adversarial input |
| Tool → tenant DB | psycopg2 queries against tenant schema; SQL injection vector via table name |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-01 | Tampering / Injection | lookup_structured table arg | mitigate | Allowlist frozenset check before any SQL string assembly; non-allowlisted returns is_error:True with no DB call. Unit test asserts psycopg2.connect not_called. Maps to hard block G-04. |
| T-04-02-02 | Tampering / Injection | lookup_structured filters dict | mitigate | All filter values passed as psycopg2 parameters (`%s` placeholders), never f-string interpolated. Filter keys are validated against a per-table column allowlist before use in WHERE clause. |
| T-04-02-03 | Information Disclosure | retrieve tool returning over-sized chunk text | mitigate | MAX_CHUNKS=5 + MAX_CHUNK_TOKENS=500 character truncation prevent runaway context inflation that could leak unrelated chunks |
| T-04-02-04 | Tampering | Escalation suppression via persona override | mitigate | escalate_to_human invocation is logged at structlog INFO level outside the LLM path; system prompt explicitly forbids "do not escalate" override (handled in agent_prompt do-not-list defaults + AI-SPEC.md §6.4 escalation metadata sync) |
| T-04-02-05 | Information Disclosure | Connection string leakage via tool logs | mitigate | _conn_str is module-level and NEVER logged; structlog calls log only agent_id and counts, never connection details |
</threat_model>
