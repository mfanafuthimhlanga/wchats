API contract from Plan 04-04:
  GET  /widget/{agent_id}/config            (public)
       → 200 {agent_id, name, theming: {primary_color, accent_gold, font_family, border_radius, background}, jwt}
  POST /widget/{agent_id}/chat              (Bearer JWT)
       body: {message: str, conversation_id: str | null}
       → 202 {job_id, status, events_url, conversation_id}
       errors: 401 (bad JWT), 429 (rate limit), 422 (oversize message), 403 (bad conv)
  GET  /widget/jobs/{job_id}/events         (public SSE — R-03)
       events: agent.thinking, agent.tool_call, agent.tool_result, agent.response, agent.escalated, agent.failed
       agent.response is terminal — widget closes EventSource on receipt

SSE event payloads (from Plan 04-03):
  agent.thinking      {agent_id, at}
  agent.tool_call     {tool_name, input, at}
  agent.tool_result   {tool_name, summary, at}
  agent.escalated     {reason, context, conversation_id, at}
  agent.response      {text, citations: [{document_name, section}], conversation_id, at}
  agent.failed        {error, at}

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
