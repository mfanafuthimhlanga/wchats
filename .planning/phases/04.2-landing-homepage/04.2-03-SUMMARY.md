## What Was Built

### Task 1: Landing Page (server component)

`apps/admin/app/page.tsx` is a pure server component with:
- Sticky 56px public mini-nav (Veridian logo + Sign in + Get started links)
- Two-column hero: left column with tag pill, 52px headline ("defensible" in wine), subtext, CTA row, proof line; right column with 4 step-pill preview cards (done/done/active/locked states)
- "HOW IT WORKS" 4-card horizontal grid with numbered wine circles
- Zero client hooks (`'use client'` absent, no `useState`, `useEffect`, `useAuth`, `getToken`)
- All CSS via inline styles with design-g token vars; zero Tailwind classNames

### Task 2: AgentCard + Dashboard

`apps/admin/app/components/AgentCard.tsx`:
- Client component with `STATUS_COLORS` map covering ready/pending/provisioning/error states
- Status chips use `--green-bg`/`--green`, `--amber-bg`/`--amber`, `--red-bg`/`--red` tokens
- Card links to `/agents/${id}` with card background `var(--bg)` + `var(--shadow-card)` per UI-SPEC §2

`apps/admin/app/agents/page.tsx`:
- Client component using `useAuth()` → `getToken()` → Bearer header — exact pattern from soul/page.tsx
- Error alert pattern replicates soul/page.tsx lines 337-351
- Empty state: centered "No agents yet." + "Create your first agent" primary CTA → /agents/new
- Header CTA: "+ Create agent" → /agents/new (primary button style)
- Agent grid: `repeat(auto-fill, minmax(280px, 1fr))` responsive layout
- `finally` block sets `loading = false` regardless of success/error
