## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04.2-02-01 | Information Disclosure | `GET /agents` enumerates agents — could leak cross-tenant list if filter missing | mitigate | `select(Agent).where(Agent.tenant_id == tenant.id, Agent.deleted_at.is_(None))` — verified by `test_list_agents_filters_by_tenant_id` |
| T-04.2-02-02 | Elevation of Privilege | IDOR on `/agents/{id}/widget-config` (read or write) | mitigate | Both routes filter SELECT by `Agent.id == agent_id AND Agent.tenant_id == tenant.id`; 404 if mismatch — verified by `test_widget_config_not_owned_returns_404` |
| T-04.2-02-03 | Tampering | XSS / CSS injection via widget color values rendered in widget iframe | mitigate | Pydantic `WidgetColorsSchema` validates every color field against `^#[0-9A-Fa-f]{6}$`; non-matching → 422. Verified by `test_save_widget_config_rejects_invalid_hex` |
| T-04.2-02-04 | Tampering | `appearance` / `launcher_shape` / `font_family` arbitrary string injection | mitigate | Pydantic `Literal[...]` constrains values; non-matching → 422 |
| T-04.2-02-05 | Information Disclosure | `font_custom_url` could be used for SSRF or tracking | accept | URL is fetched browser-side only, never server-side. Treated as user-supplied display data; CSP at widget iframe boundary is responsible for download enforcement |
</threat_model>
