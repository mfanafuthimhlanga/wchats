<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → ALB | Untrusted client traffic terminates TLS at the ALB (ACM cert) |
| ALB → ECS tasks | Private-subnet HTTP; only ALB SG may reach task port 8000 |
| ECS task → AWS services | IAM task role mediates Bedrock / S3 / Secrets access |
| CloudFront → widget S3 | OAC-only; bucket is private |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-01-01 | Information Disclosure | Secrets in image/HCL | mitigate | Secrets only as Secrets Manager ARN refs in the task `secrets` block; no literal in HCL or image (Task 1 acceptance grep) |
| T-13-01-02 | Tampering | Plaintext HTTP / SSE downgrade | mitigate | HTTPS:443 ACM listener + HTTP:80→443 301 redirect; ALB idle_timeout=4000 prevents SSE force-close (Task 2) |
| T-13-01-03 | Elevation of Privilege | Over-broad IAM | mitigate | Task role scoped: bedrock InvokeModel to titan ARN only; S3 to uploads bucket only; no `Resource:"*"` |
| T-13-01-04 | Information Disclosure | Public S3 bucket | mitigate | Block Public Access on both buckets; widget reachable only via CloudFront OAC; uploads private |
| T-13-01-05 | Spoofing/Tampering | ElastiCache open to internet | mitigate | 6379 ingress restricted to the ECS task SG; transit encryption on |
| T-13-01-06 | Denial of Service | Crashed task served as alive | accept→mitigate | ALB /health target group + ECS health_check_grace_period replaces unhealthy tasks (PROD-04); /health always-200 detects process death, not degraded state (accepted: degraded-but-up is out of scope this phase) |
</threat_model>
