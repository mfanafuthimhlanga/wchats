<objective>
Collapse the four separate `psycopg2.connect()` calls made per conversational turn in `runtime/agent.py` (one each in `_create_conversation_row`, `_validate_conversation_owner`, `_set_sdk_session_id`, `_persist_messages`) into a SINGLE pooled connection opened once at the start of `run_agent_turn` and closed in a `finally`. This is PROD-05: reuse Neon's already-stored pooled endpoint (`agent.neon_connection_string`) instead of churning four connect/close cycles per turn.

This is **ROADMAP Wave 1 (DB connection pooling on the runtime path)**.

Purpose: Cut per-turn connection churn 4→1 against Neon's PgBouncer transaction-mode pooled endpoint, lowering latency and connection pressure on the hot agent path without any new pooling infrastructure (Neon already returns the pooled URI; RDS Proxy is N/A).
Output: A refactored `run_agent_turn` that threads one open connection through its write helpers, plus a unit test asserting exactly one connect per turn.
</objective>
