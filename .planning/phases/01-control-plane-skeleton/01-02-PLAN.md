Implement the three foundational helpers that every Celery task depends on: Fernet encryption/decryption, argon2 API key hashing, the emit() event helper, and the Celery app factory with two-queue configuration.

Purpose: These are the lowest-level building blocks. Security.py establishes the encryption contract that provision_neon and apply_migrations rely on. emit() is the single function called at every task checkpoint — getting its semantics exactly right (atomic DB persist + Redis publish, always adds "at" timestamp) is critical because all SSE correctness flows from it. The Celery factory with acks_late=True global config prevents task loss on worker crash from day one.

</objective>

    - emit() calls redis.publish("job_events:{job_id}", json_string) exactly once
    - The json_string published to Redis contains keys "event_type" and "payload"

  <action>
  Write apps/api/app/services/events.py. This module is imported by Celery tasks (sync context) and by tests.

  Import: json, datetime, timezone from datetime, UUID from uuid, Session from sqlalchemy.orm, Redis as SyncRedis from redis, JobEvent from app.models.job_event.

  Implement emit(job_id: UUID, event_type: str, payload: dict | None, db: Session, redis: SyncRedis) -> None:
  1. payload = dict(payload) if payload else {}  — copy to avoid mutating caller's dict
  2. payload["at"] = datetime.now(timezone.utc).isoformat()
  3. event = JobEvent(job_id=job_id, event_type=event_type, payload=payload)
  4. db.add(event); db.commit()
  5. message = json.dumps({"event_type": event_type, "payload": payload})
  6. redis.publish(f"job_events:{job_id}", message)
  7. Return None

  The function does NOT create its own DB session or Redis connection — it accepts them as arguments. This allows callers (Celery tasks) to manage their own session lifecycle and callers (tests) to inject mocks.

  Create apps/api/app/services/__init__.py as empty file.
