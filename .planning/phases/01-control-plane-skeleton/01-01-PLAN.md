## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | config.py: NEON_ENCRYPTION_KEY | mitigate | Settings reads from env only; never log settings values; .env not committed to source (verified via .gitignore) |
| T-01-02 | Information Disclosure | config.py: CONTROL_DB_SYNC_URL | mitigate | URL in env var only; Settings class must NOT implement __repr__ that exposes field values |
| T-01-03 | Tampering | alembic_tenant migration: op.execute() DDL | accept | DDL is developer-authored, not user-provided; no injection vector at migration authoring time |
| T-01-04 | Information Disclosure | database.py: connection string in SQLAlchemy engine | mitigate | pool_pre_ping=True (no lazy logging of DSN); ensure engine does not surface DSN in exception messages |
</threat_model>
