  async def event_generator(request: Request, job_id: UUID, db: AsyncSession, redis_client: AsyncRedis) -> AsyncGenerator[ServerSentEvent, None]:

  TERMINAL_EVENTS = frozenset({"job.complete", "job.failed"})

  Phase 1 — DB replay:
  past = await db.execute(select(JobEvent).where(JobEvent.job_id == job_id).order_by(JobEvent.created_at))
  for evt in past.scalars():
      if await request.is_disconnected(): return
      yield ServerSentEvent(data=json.dumps(evt.payload), event=evt.event_type, id=str(evt.id))
      if evt.event_type in TERMINAL_EVENTS:
          return  # Already finished — do not enter subscribe phase

  Phase 2 — Redis pub/sub:
  async with redis_client.pubsub() as pubsub:
      await pubsub.subscribe(f"job_events:{job_id}")
      async for message in pubsub.listen():
          if await request.is_disconnected(): break
          if message["type"] != "message": continue
          data = json.loads(message["data"])
          yield ServerSentEvent(data=json.dumps(data["payload"]), event=data["event_type"])
          if data["event_type"] in TERMINAL_EVENTS:
              break

  In apps/api/app/api/v1/jobs.py, add GET /jobs/{job_id}/events route:
  @router.get("/jobs/{job_id}/events")
  async def stream_job_events(request: Request, job_id: UUID, db: AsyncSession = Depends(get_async_db), redis_client: AsyncRedis = Depends(get_async_redis), _: Tenant = Depends(get_current_tenant)) -> EventSourceResponse:
      response = EventSourceResponse(event_generator(request, job_id, db, redis_client))
      response.headers["X-Accel-Buffering"] = "no"
      response.headers["Cache-Control"] = "no-store"
      return response

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → FastAPI | All inbound requests cross this boundary; X-API-Key and X-Admin-Key are the only auth tokens |
| FastAPI auth dep → control DB | get_current_tenant reads tenant rows for key verification |
| SSE endpoint → Redis pub/sub | FastAPI subscribes to per-job Redis channel and forwards to client |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Spoofing | deps.py: API key verification | mitigate | argon2 verify() is timing-attack resistant; verify_api_key never raises on mismatch (returns bool) |
| T-04-02 | Information Disclosure | deps.py: X-API-Key in structlog contextvars | mitigate | api_key variable must NOT be bound to structlog context in get_current_tenant; route handlers must not log request.headers |
| T-04-03 | Information Disclosure | API error responses | mitigate | HTTPException detail strings must not include DB error messages, connection strings, or API key fragments |
| T-04-04 | Elevation of Privilege | POST /agents: tenant_id from authenticated context (not body) | mitigate | Agent.tenant_id = tenant.id (from auth dep), never from request body; client cannot spoof tenant ownership |
| T-04-05 | Elevation of Privilege | GET /agents/{id}: cross-tenant agent access | mitigate | Filter by both agent.id AND agent.tenant_id == authenticated tenant.id; 404 if not found or wrong tenant |
| T-04-06 | Spoofing | CORS: wildcard origins | mitigate | allow_origins uses settings.CORS_ORIGINS list, never "*"; widget CORS added in M4 only |
| T-04-07 | Information Disclosure | Cache-Control missing | mitigate | Cache-Control: no-store added by middleware on ALL responses including SSE; verified in acceptance criteria |
| T-04-08 | Denial of Service | SSE endpoint held open indefinitely | accept | Terminal event detection closes stream; request.is_disconnected() check cleans up orphaned connections; no explicit timeout needed in M1 |
</threat_model>
