## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Information Disclosure | CI env: NEON_ENCRYPTION_KEY in GitHub Actions logs | mitigate | Use secrets.NEON_ENCRYPTION_KEY in nightly.yml; CI unit test generates ephemeral key inline (not stored as secret) |
| T-08-02 | Denial of Service | Nightly E2E leaves orphaned Neon project if teardown fails | mitigate | Teardown step uses "if: always()" condition; project_delete called in pytest finally block AND in workflow step for double assurance |
